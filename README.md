## 📌 Sobre o projeto

Este projeto é um portfólio web desenvolvido com foco em apresentar minhas experiências, projetos e serviços de forma moderna, responsiva e interativa.

A interface utiliza uma combinação de animações, elementos visuais inspirados em tecnologia e componentes dinâmicos para criar uma experiência diferenciada para o visitante.

O projeto é desenvolvido utilizando tecnologias web nativas, sem depender de frameworks frontend.

---

## ✨ Funcionalidades

### 🌓 Tema claro e escuro

O site possui suporte a **Light Mode** e **Dark Mode**.

* Alternância manual através do botão de tema.
* Detecção automática do tema do sistema.
* Preferência salva no `localStorage`.
* Atualização automática caso o tema do sistema seja alterado.

---

### 🖥️ Monitor interativo

A página inicial possui uma representação de um monitor contendo páginas carregadas através de `iframe`.

O monitor apresenta diferentes conteúdos e possui comportamento interativo baseado na interação do usuário.

O conteúdo é carregado de forma otimizada utilizando `loading="lazy"`.

### 📁 Projetos em destaque

O portfólio possui uma seção de projetos organizada em formato de **carrossel**.

O sistema possui:

* Slides individuais.
* Indicadores de navegação.
* Troca automática de projetos.
* Navegação manual pelos indicadores.
* Pausa automática ao passar o mouse.
* Reinício da reprodução após a interação.

---

### ⚡ Animações

O projeto utiliza diversas animações CSS e SVG para criar uma identidade visual tecnológica.

Os circuitos decorativos são criados utilizando **SVG diretamente pelo JavaScript**, incluindo linhas, nós, chips e efeitos de fluxo de energia.

## 🎨 Design

O projeto utiliza uma identidade visual baseada em elementos tecnológicos, com destaque para:

* Azul como cor principal.
* Detalhes dourados.
* Efeito glassmorphism.
* Componentes com bordas arredondadas.
* Sombras e efeitos de profundidade.
* Circuitos eletrônicos decorativos.
* Interface adaptável entre temas claro e escuro.

As variáveis CSS permitem controlar grande parte da identidade visual do projeto, incluindo cores de fundo, textos, bordas, sombras, elementos do monitor e efeitos dos circuitos.

---

## 📱 Responsividade

O layout foi desenvolvido para funcionar em diferentes tamanhos de tela.

Existem regras específicas para:

* Desktop
* Tablets
* Smartphones
* Telas pequenas

Em dispositivos menores, elementos como o monitor, navegação, diferenciais, formulário e carrossel são redimensionados para manter a usabilidade.
